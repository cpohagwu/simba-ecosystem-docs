# SIMBA ecosystem documentation

Documentation for the packages that work alongside
[py-simba-pop](https://py-simba-pop.readthedocs.io), starting with
py-simba-pop-tools (calibration, validation and backtesting). Built with Sphinx
(`docs/`); examples use the synthetic farms of
[py-simba-pop-docs](https://github.com/cpohagwu/py-simba-pop-docs).

```
pip install -r docs/requirements.txt
sphinx-build -W -b html docs docs/_build/html
```
