Documentation of [py-simba-pop-tools](https://pypi.org/project/py-simba-pop-tools/), the calibration,
validation and backtesting tools for [py-simba-pop](https://py-simba-pop.readthedocs.io), the SIMBA-POP banana
cohort model. Published at [py-simba-pop-tools.readthedocs.io](https://py-simba-pop-tools.readthedocs.io), one
version per release tag (`vX.Y.Z`). Built with Sphinx (`docs/`); the examples use the synthetic farms of
[py-simba-pop-docs](https://github.com/cpohagwu/py-simba-pop-docs).

```
pip install -r docs/requirements.txt
sphinx-build -W -b html docs docs/_build/html
```
